# Loom Demo Checklist — Sector Intelligence Monitor

**Target length:** 4–6 minutes  
**Tool:** Loom (screen + mic)  
**URL to show:** http://localhost:8501 (or live Streamlit Cloud URL)

---

## Before you record

- [ ] Dashboard is running and loaded (`streamlit run app.py`)
- [ ] Browser zoom at 100% — full dashboard visible without scrolling
- [ ] Close unrelated browser tabs
- [ ] Microphone tested
- [ ] Loom recording set to "Screen + Camera" or "Screen only"

---

## Script (spoken + on-screen)

### [0:00 – 0:30] Opening — The Problem

**Say:**
> "Early-stage investors need to know where public markets are heading — not where they are today.
> The richest free source of this signal is public company earnings presentations.
> This system ingests 3 years of Paytm filings, extracts structured metrics, and surfaces an investing lens automatically."

**Show:** The README or a blank screen while talking.

---

### [0:30 – 1:00] Architecture walkthrough

**Say:**
> "The pipeline has 6 phases: fetch documents, download PDFs, parse and chunk with PyMuPDF,
> extract metrics via an LLM using a Pydantic schema, generate synthesis, and display everything
> in Streamlit. All stored in SQLite. No external services needed."

**Show:** `README.md` architecture diagram or `pipeline/` folder structure in VS Code.

---

### [1:00 – 2:00] Dashboard — Metrics tab

**Say:**
> "On first load the dashboard shows 13 quarters of Paytm data — Q4 FY23 to Q4 FY26.
> The charts are grouped by category. Let me walk through the story they tell."

**Show:**
- [ ] Click **Metrics tab**
- [ ] Point at **Scale group**: "GMV dropped to $4.1B in Q1FY25 after the PPBL disruption, and has since recovered to $5.8B — surpassing pre-disruption levels."
- [ ] Point at **Users & Devices**: "Monthly Transacting Users troughed at 7.8M and recovered to 11.5M. Soundbox devices crossed 1.25M."
- [ ] Point at **Profitability**: "Contribution margin expanded from 45% at the trough to 67% — EBITDA turned positive."
- [ ] Point at **P&L INR Cr (Screener)**: "Revenue and net profit across all 13 quarters from Screener.in — historical context going back to FY23."

---

### [2:00 – 3:00] Dashboard — Synthesis tab

**Say:**
> "The synthesis tab is the core output. Two analyses generated by LLM from the extracted data."

**Show:**
- [ ] Click **Synthesis tab**
- [ ] Read/paraphrase first 2 sentences of **Trend Analysis**
- [ ] Read/paraphrase first 2 points of **Investing Lens**
- [ ] Highlight: "Point 2 is the most actionable — Paytm has exited merchant lending. That's a clear white space for embedded lending startups targeting 12M+ merchant subscribers."

---

### [3:00 – 3:45] Dashboard — Documents tab

**Say:**
> "All source documents are tracked. Every metric links back to the filing it came from."

**Show:**
- [ ] Click **Documents tab**
- [ ] Show 5 registered Paytm IR presentations with periods and source links
- [ ] Click one link to show it opens the actual Paytm IR PDF

---

### [3:45 – 4:30] Pipeline tab — live run (optional, if API key available)

**Say:**
> "The pipeline can be re-run from the browser. Select your LLM provider, enter the API key, and hit run."

**Show:**
- [ ] Click **Pipeline tab**
- [ ] Show the 5 steps listed
- [ ] If API key available: click **Run Full Pipeline** and show the live status output

**Alternative if no API key:**
- [ ] Show `scheduler.py` in editor: "The scheduler runs this automatically every Sunday at 2am IST via APScheduler."

---

### [4:30 – 5:00] Code walk — key design decisions

**Say:**
> "Three things worth noting architecturally."

**Show:**
- [ ] Open `pipeline/schemas.py` → `FintechMetrics`: "Every field is nullable. The LLM fills what it finds — no hallucination risk from forced fields."
- [ ] Open `pipeline/extraction/metrics_extractor.py` → `_build_extraction_prompt`: "One LLM call per document. Full document context — not per-chunk calls."
- [ ] Open `pipeline/ingestion/screener_backfill.py` → `_screener_to_fiscal`: "Historical quarters from Screener.in are mapped to fiscal quarters and stored with `validated=0` — distinguishing scraped data from LLM-extracted filings."

---

### [5:00 – 5:15] Closing

**Say:**
> "The system is modular. Adding Bajaj Finance or SBI Cards is one new fetcher and a schema extension.
> Defence and Biotech schemas are already stubbed. Thank you."

**Show:** README requirements checklist section.
